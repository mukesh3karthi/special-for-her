SPECIAL FOR HER - SETUP

1. Install Node.js if not already installed.
2. Open this folder in VS Code.
3. Open Terminal in this folder.
4. Run:
   npm install
5. Run:
   npm run dev
6. Open the localhost URL shown by Vite.

PERSONALIZE
Open src/App.jsx and change:
const HER_NAME = "Her Name";

DEPLOY TO VERCEL
1. Go to vercel.com and sign in.
2. Create a new project.
3. Import this project from GitHub OR use Vercel CLI.
4. Framework preset: Vite.
5. Build command: npm run build
6. Output directory: dist
7. Deploy.

After deployment, share only the Vercel URL with her.
